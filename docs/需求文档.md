# SolidWorks 参数编辑器 — 需求文档

> 版本：v1.0 ｜ 状态：已实现 ｜ 维护：lci-ang

## 1. 项目背景与目标

### 1.1 背景

工厂日常需要反复修改 CAD 图纸尺寸（如橡胶件的胶长、孔数、边距等）。传统流程是：

```
打开 SolidWorks → 找到尺寸 → 双击修改 → 重建 → 另存 → 导出 STEP
```

一个零件有 50+ 尺寸，人工逐个查找修改效率低、易出错，且无法批量生成多个型号变体。

### 1.2 目标

让 **AI / 命令行工具** 接管"改参数"环节，实现：

1. 用自然语言或命令行直接修改零件尺寸
2. 支持 SolidWorks 方程式驱动的参数联动（改一个变量，所有关联尺寸自动更新）
3. 一键批量生成多个型号变体（SLDPRT + STEP）
4. 修改可回退，原件永不丢失
5. 提取零件全部参数与方程式，建立可维护的知识库

### 1.3 非目标（明确不做）

- ❌ 从零建模（AI 只改已有零件，不创建新零件）
- ❌ 工程图自动标注（后续版本）
- ❌ 装配体自动化（后续版本）
- ❌ 跨平台（仅 Windows + SolidWorks）

## 2. 用户与使用场景

| 角色 | 使用方式 | 典型操作 |
|------|---------|---------|
| 工程师（本项目维护者） | Hermes 对话 / 终端 CLI | "边沿孔数量改成 3"、"导出 STEP" |
| 工厂操作员（未来） | 终端 CLI（只读/固定脚本） | 运行预设的批量出图脚本 |

### 2.1 核心场景

**场景 A：单参数修改（日常）**
```
用户: "边沿孔数量改成 3"
系统: 匹配参数 → 检查标准 → 修改方程式 → 重建 → 保存
```

**场景 B：批量出图（一次生成多个型号）**
```
用户: "生成标准款、加长款、短款三个型号"
系统: 读配置 → 逐个修改 → 各输出 SLDPRT + STEP
```

**场景 C：修改出错回退**
```
用户: "改错了，回退"
系统: 从快照恢复全部参数 → 重建 → 保存
```

## 3. 功能需求

### 3.1 参数提取（FR-1）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-1.1 | 提取零件全部尺寸参数（名称、当前值） | P0 |
| FR-1.2 | 提取 SolidWorks 方程式（全局变量、公式、备注） | P0 |
| FR-1.3 | 提取自定义属性（代号、名称、材料、日期等） | P1 |
| FR-1.4 | 输出为 JSON 文件，供标注和后续使用 | P0 |

### 3.2 参数修改（FR-2）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-2.1 | 支持按参数全名修改（`D1@草图1@Part.Part`） | P0 |
| FR-2.2 | 支持按短名修改（`D1@草图1`、`L`） | P0 |
| FR-2.3 | 支持按中文标签修改（`边沿孔数量=3`） | P0 |
| FR-2.4 | 修改方程式全局变量时**保留备注**（`'边沿孔数量`） | P0 |
| FR-2.5 | 公式驱动变量（如 F）禁止直接修改，提示改用驱动变量 | P0 |
| FR-2.6 | 修改后自动重建模型（EditRebuild3） | P0 |
| FR-2.7 | 修改后自动保存 SLDPRT | P0 |

### 3.3 文件输出（FR-3）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-3.1 | 支持导出 STEP 文件 | P0 |
| FR-3.2 | 支持另存为新 SLDPRT（不覆盖原件） | P0 |
| FR-3.3 | 支持批量生成多个变体（SLDPRT + STEP） | P1 |
| FR-3.4 | 输出目录自动创建 | P1 |

### 3.4 回退保护（FR-4）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-4.1 | 首次修改前自动保存全量快照 | P0 |
| FR-4.2 | 支持一键回退到快照状态 | P0 |
| FR-4.3 | 支持手动重置快照基线（确认当前状态） | P1 |

### 3.5 交互方式（FR-5）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-5.1 | Hermes Skill：自然语言对话修改 | P0 |
| FR-5.2 | 终端 CLI：`sw_cli.py` 交互式命令行 | P0 |
| FR-5.3 | CLI 支持 list/rollback/snapshot/save/save-as/step/export 命令 | P0 |

### 3.6 知识库（FR-6）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-6.1 | `params_labeled.json`：参数名 → 中文标签 → 值 | P0 |
| FR-6.2 | `standards.md`：零件设计标准与变量依赖关系 | P1 |
| FR-6.3 | 中文标签用于 CLI 和 AI 的模糊匹配 | P0 |

## 4. 非功能需求

| 编号 | 需求 | 说明 |
|------|------|------|
| NFR-1 | 兼容 SolidWorks 2018+ | 实测于 SW2022 |
| NFR-2 | Windows + pywin32 | COM 自动化 |
| NFR-3 | 单次修改 ≤ 30 秒 | 不含 SW 启动时间 |
| NFR-4 | 原件永不损坏 | 默认另存模式 + 快照回退 |
| NFR-5 | 代码通用化 | 无硬编码路径/零件名，可公开 |

## 5. 术语表

| 术语 | 含义 |
|------|------|
| SLDPRT | SolidWorks 零件源文件（可编辑原件） |
| STEP | 通用 CAD 交换格式（交付件） |
| STL | 三角网格格式（3D 打印用） |
| 全局变量 | SolidWorks 方程式中的命名变量（如 L、N1） |
| 方程式 | 驱动尺寸间关系的公式（如 F=(L-A-C-2Q)/(N1-1)） |
| 备注 | 方程式 `'` 后的中文注释 |
