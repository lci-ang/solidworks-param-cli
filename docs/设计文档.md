# SolidWorks 参数编辑器 — 设计文档

> 版本：v1.0 ｜ 状态：已实现 ｜ 维护：lci-ang

## 1. 系统架构

```
┌─────────────────────────────────────────────────────┐
│                    使用层                            │
│  Hermes AI 对话       终端 CLI (sw_cli.py)           │
│   "孔数改成3"          > 边沿孔数量=3                 │
└──────────────┬──────────────────┬───────────────────┘
               │                  │
┌──────────────▼──────────────────▼───────────────────┐
│                  脚本层 (scripts/)                    │
│  sw_cli.py           交互式 CLI（常驻 SW 连接）        │
│  sw_modify.py        单次修改（支持 --save-as/--batch）│
│  extract_full.py     完整提取（方程式+属性+尺寸）       │
│  extract_sw_params.py 尺寸提取                        │
└──────────────┬───────────────────────────────────────┘
               │ pywin32 COM (Dispatch)
┌──────────────▼───────────────────────────────────────┐
│                SolidWorks 2022 (COM API)             │
│  ModelDoc2 / EquationMgr / FeatureManager            │
└──────────────────────────────────────────────────────┘
```

## 2. 核心设计决策

### 2.1 为什么用 pywin32 COM 而非 SW 宏/Add-in

| 方案 | 优点 | 缺点 | 选择 |
|------|------|------|------|
| pywin32 COM | Python、可被 Hermes 调用、无需编译 | 单线程、无 UI | ✅ |
| SW VBA 宏 | SW 内置 | 语言受限、无法被外部调用 | ❌ |
| C# Add-in | 全功能 | 需编译、开发重 | ❌ |

### 2.2 参数解析三层匹配

用户输入 → 三层解析：

```
输入 "边沿孔数量=3"
  ↓ 第1层: 方程式全局变量名      (N1, A, C, L, Q, F, N2)
  ↓ 第2层: 中文标签映射          (边沿孔数量 → N1)  ← params_labeled.json
  ↓ 第3层: 尺寸短名 → 全名映射   (L → L@凸台-拉伸1@Part.Part)
  → 找到 N1 → 修改方程式
```

**为什么需要第3层**：SolidWorks 返回的全名是 `L@凸台-拉伸1@MyPart.Part`，用户不可能记住，需要短名映射（split by `@` 取前 2 段）。

### 2.3 方程式备注保留

修改方程式时必须保留 `'` 后的中文备注：

```
原始:  "N1"= 5'边沿孔数量
修改:  "N1" = 3'边沿孔数量   ← 备注必须保留！
```

实现：`eq.split("'", 1)[1]` 提取备注，拼回新方程式字符串。

### 2.4 公式驱动变量保护

`F`、`N2` 是公式驱动变量（右侧含 `+ - * / (`），直接赋值会破坏公式。
修改时检测右侧是否含运算符，含则拒绝并提示改驱动变量。

### 2.5 快照回退机制

```
首次修改 ──→ 自动存快照 .sw_snapshots/<part>_last.json
  │              （方程式原文 + 尺寸值 全量）
  ▼
后续修改 ──→ 快照不变（只存第一次的状态）
  │
  ▼
--rollback ──→ 恢复方程式原文 + 尺寸值 → 重建
--new-snapshot → 当前状态存为新快照（重置基线）
```

**关键决策**：快照只在首次修改时保存，避免"回退到上次修改后"而非"回退到原始状态"。

## 3. 模块设计

### 3.1 sw_cli.py（交互式 CLI）

**状态**：常驻 SW 连接，保持模型打开。

```
初始化: Dispatch(SldWorks) → OpenDoc → 读方程式/尺寸/标签 → 存快照(首次)
主循环: input("> ") → 解析命令 → 执行 → 显示结果
命令:   参数=值 | list | rollback | snapshot | save | save-as | step | export | exit
```

**内存模型**：修改直接作用于已打开的模型（`eq_mgr.Equation(i, ...)` / `param.SystemValue`），
不写盘直到 `save`/`save-as`。退出时提示保存。

### 3.2 sw_modify.py（单次/批量修改）

```
参数: <SLDPRT> [PARAM=VAL...] [--step OUT] [--save-as OUT] [--batch JSON]
流程: OpenDoc → 存快照(首次) → 三层匹配修改 → EditRebuild3 → 显示方程式 → 保存/另存 → 导出STEP
```

`--batch`：读 JSON 变体列表，逐个 OpenDoc（先 CloseAllDocuments 避免冲突）→ 修改 → 另存 → 导出。

### 3.3 extract_full.py（完整提取）

```
流程: OpenDoc → 遍历特征树收集尺寸 → GetEquationMgr 收集方程式 → CustomPropertyManager 收集属性 → 输出 JSON
```

**遍历特征树**（关键实现）：
```
model.FirstFeature
  → feat.GetFirstDisplayDimension → feat.GetNextDisplayDimension(prev)
  → feat.GetFirstSubFeature → sub.GetNextSubFeature
```
不能用 `Extension.GetDimensions()`（不存在），必须手动遍历。

### 3.4 知识库文件

```
params_labeled.json    中文标签 → 参数映射（CLI/AI 模糊匹配用）
standards.md           设计标准 + 变量依赖关系（AI 上下文）
```

## 4. 数据格式

### 4.1 params_labeled.json

```json
{
  "part_name": "MyPart",
  "sldprt_path": "C:\\parts\\MyPart.SLDPRT",
  "equations": {
    "L":  { "value": 100.0, "label": "总长", "drives": ["D1@凸台-拉伸2"] },
    "N1": { "value": 5,     "label": "边沿孔数量", "drives": ["D1@阵列(线性)1"] }
  },
  "dimensions": {
    "D1@草图1": { "value": 30.0, "label": "胶条宽度" }
  }
}
```

### 4.2 批量配置 batch_config.json

```json
[
  {"name": "标准款", "changes": {"L": 100, "N1": 5}, "step": true},
  {"name": "加长款", "changes": {"L": 120, "N1": 5}, "step": true}
]
```

### 4.3 快照文件 .sw_snapshots/<part>_last.json

```json
{
  "timestamp": "2026-07-23 15:20:37",
  "equations": {"0": {"equation": "\"A\"= 20'胶面边距A", "value": 20.0}},
  "dimensions": {"D1@草图1@MyPart.Part": 30.0}
}
```

## 5. pywin32 COM 兼容层（踩坑记录）

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| `GetTitle()` 报错 | COM 属性被当方法调用 | 不加括号 `model.GetTitle` |
| `EditRebuild3()` 报错 | 同上 | `model.EditRebuild3` |
| `OpenDoc6` 类型不匹配 | ByRef 参数 pywin32 不支持 | 用 `OpenDoc(path, 1)` |
| `Extension.GetDimensions()` 不存在 | API 名称错误 | 手动遍历特征树 |
| `SaveAs` 参数过多 | pywin32 动态模式参数限制 | 只传文件名 |
| `Save3(0)` 失败 | 参数签名问题 | try 链降级 `Save3(0,None,None)` → `Save3(0)` → `Save2` → `Save` |
