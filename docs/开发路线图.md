## 路线图

### 阶段二：效率工具（短期）

| 优先级 | 功能 | 说明 | 涉及 |
|--------|------|------|------|
| 🥇 | 质量自动计算 | 改完输出重量/体积/重心 | GetMassProperties |
| 🥈 | 截图预览 | 改完自动截图给用户看 | ViewZoomTo2 + SaveAs png |
| 🥉 | 版本对比 | 两个变体差异自动对比 | 解析方程式值 |

### 阶段三：图纸自动化（中期）

| 优先级 | 功能 | 说明 | 涉及 |
|--------|------|------|------|
| 🥇 | 工程图自动生成 | 三视图+标注+PDF | IDrawingDoc |
| 🥈 | 图纸信息自动填写 | 代号/重量/日期入标题栏 | CustomPropertyManager |
| 🥉 | 配置管理 | 一个文件存多型号 | ConfigurationManager |

### 阶段四：装配与解析（长期）

| 功能 | 说明 |
|------|------|
| 装配体自动化 | AddComponent5 + AddMate5 + 干涉检查 |
| STEP 反向解析 | FeatureWorks 识别特征提参数 |
| 材质切换 | SetMaterialPropertyName |

## 开发约定

1. **代码通用化**：无硬编码零件名/路径/屏幕尺寸，可公开
2. **隐私保护**：提交 GitHub 前 grep 检查姓名/公司/零件名
3. **文档同步**：改代码必须同步更新 SKILL.md + README + docs/
4. **测试先行**：每个新功能用真实零件验证（改值→重建→导出）
5. **需求变更**：需求文档是锚点，需求变了先改文档再改代码
