## 1. 这个工具是干什么的

以前改 SolidWorks 零件尺寸：

```
打开 SolidWorks → 找到尺寸 → 双击 → 输入新值 → 重建 → 导出
```

用这个工具：

```
> 边沿孔数量=3
```

一条命令搞定，而且**自动处理连带变化**（比如孔数变了，孔间距会自动重算）。

**它能做 4 件事：**

| 功能 | 例子 | 效果 |
|------|------|------|
| 改参数 | `边沿孔数量=3` | 修改尺寸/方程式变量 |
| 看参数 | `list` | 列出所有可改的参数和中文名 |
| 出图 | `export 加长款` | 另存为新 SLDPRT + 导出 STEP |
| 反悔 | `rollback` | 恢复到修改前的状态 |

## 2. 安装（第一次用，做一次就行）

### 需要准备的东西

| 需要 | 怎么检查 | 没有怎么办 |
|------|---------|-----------|
| Windows 电脑 | 你是 Windows 就行 | — |
| SolidWorks 2018 以上 | 能正常打开零件就行 | 先装 SolidWorks |
| Python 3.8 以上 | 见下面步骤 | 去 python.org 下载安装 |

### 检查 Python 有没有装

打开**命令提示符**（开始菜单搜索"cmd"），输入：

```bash
python --version
```

- 显示 `Python 3.8.x` 或更高 → ✅ 可以继续
- 显示"不是内部或外部命令" → ❌ 去 https://www.python.org/downloads/ 下载安装，**安装时勾选 "Add Python to PATH"**

### 安装配套库

在命令提示符里输入：

```bash
pip install pywin32
```

> 这是让 Python 能控制 SolidWorks 的桥梁。**只需要装一次。**
> 如果双击启动时提示需要安装，程序会自动帮你装，不用手动。

### 放好你的零件

把工具文件夹和你的零件放在**同一个大文件夹**里，例如：

```
D:\我的零件\
├── solidworks-param-editor\     ← 工具文件夹（整个复制过来）
└── 各种零件.SLDPRT              ← 你的零件
```

> 工具启动时会自动在这个大文件夹里找所有零件。

## 3. 启动（每次用）

### 方法一：双击启动（推荐，新手用这个）

双击工具文件夹里的 **`启动参数编辑器.bat`**

会自动弹出终端窗口，显示：

```
找到以下 SolidWorks 零件:
  [1] 我的零件.SLDPRT
      D:\我的零件\
  [2] 垫片.SLDPRT
      D:\我的零件\橡胶件\
  [0] 退出

选择零件编号:
```

### 方法二：命令行启动

```bash
# 指定零件文件夹（会扫描里面的零件）
python scripts\sw_cli.py "D:\我的零件"

# 或者直接指定零件文件
python scripts\sw_cli.py "D:\我的零件\我的零件.SLDPRT"
```

## 4. 第一次使用：选择零件

启动后按提示输入编号，按回车：

```
选择零件编号: 1
```

然后会显示：

```
========================================================
  SolidWorks 参数编辑器
  零件: 我的零件
  方程式: 17 条 | 尺寸: 67 个
  输入 help 查看命令, exit 退出
========================================================

```

看到 `>` 提示符，就说明进入工具了，可以开始操作。

> ⚠️ **注意**：SolidWorks 软件本身需要是打开的（不用打开零件文件，软件在运行就行）。

## 5. 日常操作

### 5.1 改一个参数

在 `>` 后面输入，按回车：

```
> 边沿孔数量=3
```

看到 ✅ 就成功了：

```
✅ [方程式] N1: 10.0 -> 3.0 '边沿孔数量
```

工具会显示改了什么、改成了什么。

> 参数名可以用**中文标签**（边沿孔数量）、**短名**（N1）或**全名**（D1@阵列(线性)2）。
> 不知道有哪些参数？输入 `list` 查看。

### 5.2 保存

改完参数后**还没保存到文件**，输入：

```
> save
```

看到 `💾 已保存` 说明写入了零件文件。

> 工具默认"改了不保存"——防止你误操作改坏了原件。确认没问题再 save。

### 5.3 另存为新文件（不碰原件）

想要"改完保存成另一个零件"（比如生成加长款）：

```
> export 加长款
```

会输出两个文件到零件的 `output` 文件夹：

```
output\
├── 加长款.SLDPRT    ← 可编辑的新零件
└── 加长款.STEP      ← 给别人看的通用格式
```

**原零件文件完全没被动过。** 这是最安全的使用方式。

### 5.4 改错了，反悔

改坏了没关系！输入：

```
> rollback
```

恢复到**第一次修改前**的状态（工具在你第一次修改时自动拍了快照）。

### 5.5 查看所有可改参数

```
> list
```

显示全部方程式、尺寸、中文标签：

```
=== 方程式 (17) ===
  "A"= 20'胶面边距A  =>  20.0 [全局变量]
  "N1"= 5'边沿孔数量  =>  5.0 [全局变量]
  ...

=== 中文标签 ===
  胶面边距A -> A
  边沿孔数量 -> N1
  总长 -> L
  ...
```

### 5.6 切换零件

想换一个零件操作：

```
> switch
```

会重新弹出零件选择列表。

### 5.7 退出

```
> exit
```

如果有没保存的修改，会问你要不要保存。

## 6. 常用命令速查表

| 命令 | 作用 | 例子 |
|------|------|------|
| `参数名=值` | 修改参数 | `边沿孔数量=3` |
| `list` | 查看所有参数 | `list` |
| `save` | 保存到原件 | `save` |
| `save-as 名称` | 另存为新 SLDPRT | `save-as 加长款` |
| `step 名称` | 导出 STEP | `step 加长款` |
| `export 名称` | 另存 + 导出 STEP | `export 加长款` |
| `rollback` | 回退到修改前 | `rollback` |
| `snapshot` | 把当前状态设为新起点 | `snapshot` |
| `switch` | 切换零件 | `switch` |
| `help` | 显示帮助 | `help` |
| `exit` | 退出 | `exit` |

**提示：**
- 等号两边有没有空格都行：`边沿孔数量=3` 和 `边沿孔数量 = 3` 都可以
- 输入 `list` 里的中文标签名可以直接用

## 7. 常见问题

**Q1: 双击 .bat 后窗口一闪而过？**
先确认：① Python 装了没（见安装章节）；② 弹窗里的错误信息是什么。通常是没有 Python 或没装 pywin32。

**Q2: 提示"没找到 .SLDPRT 零件文件"？**
工具扫描的是**工具文件夹的上一级目录**（见安装章节的文件夹结构）。把你的零件放到工具文件夹旁边，或者用命令行指定路径。

**Q3: 提示"找不到参数"？**
先输入 `list` 看看可用参数名。可能是你记的名字和实际标签不完全一样，`list` 会显示所有中文标签。

**Q4: 提示"公式驱动变量，直接改会破坏公式"？**
有些参数（如孔间距 F）是**算出来的**，不是直接存的。改它的驱动变量（比如孔数量 N1）就会自动重算。不要强行改它。

**Q5: SolidWorks 弹窗卡住/没反应？**
SolidWorks 软件要处于运行状态（开着，不用打开文件）。如果它正在做大型渲染，等它完成再操作。

**Q6: 改完保存了，怎么恢复？**
如果还没关工具：`rollback`。如果已经关了：你改之前的快照文件在零件文件夹的 `.sw_snapshots` 里，重新启动工具后第一次修改前会自动用旧快照。

**Q7: 这个工具会弄坏我的原件吗？**
不会。只要你用 `export`/`save-as`（另存）而不是 `save`（覆盖），原件永远不变。`rollback` 也是你的保护网。

## 8. 名词解释

| 名词 | 意思 |
|------|------|
| SLDPRT | SolidWorks 零件源文件（能继续编辑的） |
| STEP | 通用 3D 格式，任何软件都能打开（发给别人用这个） |
| STL | 3D 打印用的网格格式 |
| 方程式 | SolidWorks 里的公式，让尺寸自动联动 |
| 全局变量 | 方程式里的名字（如 N1、L），改一个带动一片 |
| 快照 | 工具自动保存的"修改前状态"，rollback 就是回到这里 |
| 标签 | 参数的中国人话名字（边沿孔数量 = N1） |
| output | 另存/导出文件的默认输出文件夹 |

## 最后：给新手的 3 条安全建议

1. **第一次先玩 `list` 和 `export`**——不改原件，随便试
2. **重要零件先复制一份**再操作，双保险
3. **改完先 `export` 验证**，确认效果对了再 `save`
